## Keyword 정리

## 3계층 아키텍처 이외에 어떤 아키텍처들이 있을까?

Hexagonal architecture: 비즈니스 로직을 DB나 API와 같은외부 기술로부터 완전히 분리.

MVC: 3계층과 유사하지만 원래는 프론트엔드 화면까지 포함한 패턴.

## SQL Injection을 포함한 대표적인 웹 보안 공격 기법

세션 하이재킹: 세션 ID 탈취로 사용자 위장. HTTPS, 세션 재발급으로 방어.

XSS: 악성 스크립트를 웹페이지에 삽입해 다른 사용자 브라우저에서 실행되게 함.

## 커넥션 풀(Connection Pool)이란?

DB와의 연결을 매번 새로 맺지 않고, 미리 일정 개수를 만들어 재사용하는 기법.
연결 생성/해제는 비용이 크기 때문에, 풀링으로 성능을 크게 개선.
Spring Boot는 HikariCP를 기본 채택.

## Raw SQL vs ORM

Raw SQL은 개발자가 쿼리를 직접 작성해서 세밀한 제어가 가능하지만 오타나 파라미터 순서실수 문제에 취약하고 스키마 변경시 관련 쿼리를 일일이 수정해야하는 유지보수 부담이 크다. ORM은 테이블을 객체로 매핑해 메서드 호출만으로 쿼리를 자동 생성해줘 생산성이 높지만 내부쿼리가 감춰져있어서 비효율 문제 발생가능.

## INSERT 외에 데이터를 다루는 핵심 SQL 문법

대표적으로 CRUD가 있음.

- Create(생성) - Insert
- Read(조회) - Select
- Update(수정) - Update
- Delete(삭제) - Delete
