## ⭐️미션 제출 방법⭐️

> mission 디렉토리 안에 backend 또는 frontend, 그 안에 chapter00 형식으로 디렉토리 생성

```bash
mission
├── backend
│   └── chapter00
│       ├── README.md
│       └── images/
└── frontend
    └── chapter00
        ├── README.md
        └── images/
```

1. 로컬에서 mission/backend 또는 mission/frontend 디렉토리 안에 chapter?? 디렉토리 생성 및 미션 인증 파일(README.md) 작성
- 예시) 1주차 Backend 미션 : mission/backend/chapter01/README.md
- 예시) 1주차 Frontend 미션 : mission/frontend/chapter01/README.md
- 이미지가 필요한 경우 각 chapter 디렉토리의 images 폴더에 첨부
2. fork한 본인 레포에 커밋 후 push
3. pull request 생성 후 이슈 및 리뷰어 연결
4. 교육국장이 승인하면(메일이 올거에요) 직접 merge
